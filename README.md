# Recovering the Record

A demonstration built on the published Ankara Bağ Evi collection of Koç University
VEKAM (Koç University Vehbi Koç Ankara Studies Research Center). It shows how much of
what the curators record is lost when the collection is exported to Dublin Core, and
what that information looks like when it is mapped to CIDOC CRM instead.

Live page: https://catavei.github.io/recovering-the-record/

All records and images belong to Koç University Libraries / VEKAM. Thumbnails are
loaded from the library's public IIIF server and are not stored in this repository.
